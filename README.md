# yoni

Landing pages for Yoni’s real estate businesses.

## Projects

- `web/` — **ProbateDoctors** (React + Vite + Tailwind)
- `value-for-casa/` — **Value for Casa** (Vite + HTML/CSS/JS)

## Run locally

### ProbateDoctors

```bash
cd web
npm install
npm run dev
```

### Value for Casa

```bash
cd value-for-casa
npm install
npm run dev
```
